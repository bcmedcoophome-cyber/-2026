# 생애말기활동가기록지 (휴대폰 앱)

생애말기 돌봄 활동가가 방문 후 휴대폰으로 **버튼만 눌러** 기록을 남기면 구글 드라이브에 저장되는 웹앱입니다.
「재택의료 방문상담」 앱(`home-visit/`)과 같은 방식이고, 어르신 활동가용이라 **글자·버튼이 크게** 만들어져 있습니다.

## 화면 순서

1. **내 이름**: 팀 버튼(따품안·임종하면·해바라기·햇살동행) → 내 이름. 한 번 고르면 휴대폰이 기억합니다. [바꾸기]로 변경
2. **방문날짜**: 오늘 날짜가 자동으로 들어감 (달력으로 변경 가능)
3. **어르신 이름**: 직접 입력. 전에 보낸 어르신은 아래에 버튼으로 나옴
4. **대화상대** (여러 개): 대상자 본인 · 자녀 · 요양보호사 · 배우자 · 기타
5. **대상자 기분·상태** (여러 개): 활발 · 우울 · 무기력 · 수면 · 통증 · 기타
6. **의료진 전달사항**: 없음 / 있음 → '있음'이면 **전달 내용** 칸이 나타나고 꼭 적어야 함 (기록지에 빨간 글씨로 강조)
7. **활동 내용·특이사항** (선택): 자주 쓰는 문구 버튼, 키보드 마이크로 말로 입력 가능

빈 칸이 있으면 그 칸이 빨간 테두리로 표시됩니다. 오른쪽 위에 `3 / 6`처럼 진행 개수가 보이고, 다 채우면 `✓ 다 했어요`.

## 아래 버튼 3개

| 버튼 | 하는 일 |
|---|---|
| **NEW** | 새 기록 시작. 쓰던 기록은 [저장한 기록 보기]에 자동 보관 |
| **저장** | 휴대폰에 보관 + 시트에 '임시저장' 줄 (다시 누르면 같은 줄이 바뀜) |
| **전송** | 확인 화면 → [보내기] → 기록지(구글 문서) 만들고 같은 줄을 '전송완료'로 |

인터넷이 끊겨 못 보내면 휴대폰에 보관했다가 **[다시 보내기]** (같은 기록은 두 번 저장되지 않음).
입력 중인 내용은 자동으로 휴대폰에 저장되어 창을 닫아도 남습니다.

## 드라이브 저장 위치

「방문기록지」 폴더 (`Code.gs` 맨 위 `TARGET_FOLDER_ID`)

```
방문기록지/
├─ 생애말기활동가 기록부        ← 구글 시트 1개
│    ├─ [전체목록] 탭: 모든 기록 한 줄씩 (종류·날짜·어르신·활동가·상태·알림·기록지 링크)
│    ├─ [방문기록지] 탭: 방문기록지 항목 전체
│    └─ [첫방문] 탭: 첫방문 항목 전체 (첫방문 기록이 생기면 자동으로 생김)
├─ 이명옥/
│   └─ 2026-10/
│       └─ 생애말기활동가기록지_홍길동_이명옥_2026-10-25
└─ 홍경기/ ...
```

시트는 파일 → 다운로드 → Microsoft Excel(.xlsx)로 엑셀 파일로 받을 수 있습니다.

   ("확인되지 않은 앱"이 나오면 고급 → 이동 → 허용). 로그에 폴더·시트 주소와 "화면: GitHub에서 불러옴"이 나오면 성공

   - 배포 → **웹 앱 URL** 복사 → 활동가 휴대폰에서 열고 **홈 화면에 추가**

## 그다음부터는 자동 반영

휴대폰 화면(`Index.html`)은 앱이 열릴 때 **GitHub `claude/end-of-life-record` 브랜치의 `end-of-life/Index.html`** (main은 건드리지 않음) 을 읽어 옵니다.
그래서 항목·명단·탭·디자인을 고치면 GitHub에 올라간 뒤 **5분 안에** 휴대폰에 반영되고, 다시 배포할 필요가 없습니다.
(바로 확인하려면 웹 앱 주소 끝에 `?fresh=1`을 붙여 여세요.)
화면 맨 아래 `화면 2026-10-25b · 서버 2026-10-25b`로 어느 버전인지 알 수 있습니다.

`Code.gs`(서버)를 고쳐야 할 때만 다시 붙여넣고 **배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포** 를 합니다.
("새 배포"를 누르면 주소가 바뀌니 누르지 마세요.) 서버는 기록 종류·항목이 늘어나도 그대로 쓸 수 있게 만들어 두었습니다.

## 명단·항목 바꾸기

- 활동가 명단: `Index.html`의 `const TEAMS = [ ... ]`
- 기록 항목: `Index.html`의 `const FORM = [ ... ]` (`label`이 시트 열 이름이 되며, 새 항목은 열이 자동으로 생김)
