# 재택의료 사회복지 방문상담 체크리스트

방문 중(30분 안팎) 휴대폰으로 **톡톡 체크만 하면** 상담기록이 바로 **구글 드라이브**에 저장되는 웹앱입니다.

- ✅ 큰 버튼으로 체크 → 타이핑 최소화 (상담 메모는 키보드 🎤 음성입력 추천)
- 🔁 **재방문 자동 채우기**: 환자명을 고르면 지난 기록의 생년월일·장기요양등급·장기요양기관·주거·동거형태·경제상태·이용서비스가 자동으로 채워져서, 바뀐 것만 고치면 됩니다
- ⚠ **위기신호**(학대·자살위험·돌봄공백 등)를 체크하면 화면 상단에 빨간 경고가 뜨고, 기록지에도 강조 표시됩니다
- ⏱ 방문 경과 시간 표시 (25분이 지나면 빨간색)
- 💾 입력하는 즉시 휴대폰에 자동 임시저장 → 창을 닫아도 그대로 남아 있음
- 📁 전송하면 「방문기록지_환자명_작성자_날짜」 구글 문서가 지정 폴더에 자동으로 만들어짐
- 📶 엘리베이터·지하처럼 신호가 없는 곳에서 전송이 실패하면 휴대폰에 보관했다가 **"다시 보내기"** (신호가 잡히면 자동으로 재전송, 중복 저장 안 됨)
- 📋 **요약복사**(전송 확인 화면): 전자의무기록(EMR)이나 팀 메신저에 그대로 붙여넣기

## 화면 아래 버튼 3개

| 버튼 | 하는 일 |
|---|---|
| **NEW** | 새 방문 시작. 쓰던 기록이 있으면 자동으로 [저장] 목록에 보관하고 비웁니다 |
| **저장** | 지금 기록을 **휴대폰에 보관 + 스프레드시트에 '임시저장'으로 기록** (문서는 아직 안 만듦). 다시 저장하면 같은 줄이 갱신됨. 위쪽 [목록]에서 불러와 이어서 쓰거나 전송 |
| **전송** | 확인 화면 → **방문기록지(구글 문서)를 드라이브 폴더에 만들고** 시트의 같은 줄을 '전송완료'로 변경. 확인 화면에서 [요약복사]도 가능 |

방문 중에는 체크만 하고 [저장] → 차로 이동하거나 센터에 돌아와서 [목록]에서 불러와 메모를 보충하고 [전송]하는 식으로 쓰면 편합니다.

## 드라이브에 저장되는 내용

전송하면 센터 드라이브의 **「환자별 방문기록지 (사회복지)」** 폴더에 저장됩니다.
(`Code.gs` 맨 위 `TARGET_FOLDER_ID`에 폴더 ID가 들어 있습니다. 다른 폴더로 바꾸려면 폴더 주소의 `folders/` 뒤 부분으로 바꾸세요.)

```
환자별 방문기록지 (사회복지)/
├─ 방문기록지_김순자_이복지_2026-10-13     ← 구글 문서 (방문 1건 = 1개)
├─ 방문기록지_홍길동_이복지_2026-10-13
└─ 재택의료 방문상담 기록부               ← 구글 시트: 방문 1건 = 1줄 (통계·재방문 자동 채우기용)
```

파일 이름은 **방문기록지_환자명_작성자_방문일** 입니다. 폴더 검색창에 환자 이름을 치면 그 환자의 기록지가 모두 나옵니다.
방문기록지에는 인적사항 표(환자명·생년월일·방문일·방문유형·장기요양등급·장기요양기관), 위기신호, 항목별 체크 내용, 상담내용·향후 계획, 작성일시·작성자(서명) 칸이 들어가며 바로 출력하거나 PDF로 내려받을 수 있습니다.

## 설치 (처음 한 번, 약 5분)

1. **폴더 주인 계정(bcmedcoophome@gmail.com)** 으로 <https://script.google.com> 접속 → **새 프로젝트**
2. 왼쪽 위 프로젝트 이름을 `재택의료 방문상담`으로 변경
3. `Code.gs`의 기존 내용을 모두 지우고, 이 폴더의 **`Code.gs` 내용 전체를 붙여넣기**
4. 파일 옆 **＋ → HTML** 을 눌러 이름을 `Index`로 만들고, **`Index.html` 내용 전체를 붙여넣기**
5. (선택) ⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"를 켜고 `appsscript.json` 내용 붙여넣기 (시간대를 한국으로 고정)
6. 위쪽 함수 선택에서 **`setup`** 을 고르고 **▶ 실행** → 권한 승인
   - "확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용** (내가 만든 스크립트라서 나오는 정상 경고입니다)
   - 실행 로그에 폴더와 시트 주소가 나오면 성공 (「환자별 방문기록지 (사회복지)」 폴더에 기록부 시트가 생깁니다)
7. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** (혼자 쓸 때)
   - **배포** → 나오는 **웹 앱 URL**을 복사
8. 휴대폰에서 그 URL을 열고 **홈 화면에 추가**
   - 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(크롬): ⋮ → 홈 화면에 추가

### 사회복지사 여러 명이 함께 쓸 때

1. 위 6단계까지 관리자 1명이 진행 → **「환자별 방문기록지 (사회복지)」 폴더를 팀원에게 "편집자"로 공유**
2. 스크립트 프로젝트도 팀원에게 공유 (오른쪽 위 사람 아이콘)
3. 7단계 배포 설정을 다음처럼 변경
   - 다음 사용자 인증 정보로 실행: **웹 앱에 액세스하는 사용자**
   - 액세스 권한: **Google 계정이 있는 모든 사용자** (구글 워크스페이스라면 "도메인 내 모든 사용자")
4. 팀원은 URL을 처음 열 때 권한을 한 번 승인하면 됩니다. 시트의 `구글계정` 열에 누가 썼는지 자동으로 남습니다.

> 폴더 공유를 받지 않은 사람은 저장이 되지 않으므로 환자 정보가 밖으로 새지 않습니다.

## 체크 항목 바꾸기

`Index.html` 안의 `const FORM = [ ... ]` 부분만 고치면 됩니다.

```js
{ key: 'mood', label: '정서상태', type: 'single', options: ['안정', '다소 저하', '우울 의심'] },
```

- `type`: `single`(하나만 선택) · `multi`(여러 개) · `text` · `date` · `memo`(긴 글)
- `carry: true` → 재방문 때 지난 기록에서 자동으로 채움
- `label`이 시트의 열 이름이 됩니다. 새 항목을 추가하면 시트에 열이 자동으로 생깁니다.
- 수정 후에는 **배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포** 를 해야 휴대폰에 반영됩니다 (URL은 그대로).
