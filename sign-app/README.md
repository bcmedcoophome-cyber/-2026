# 문자서명 (서명만 받는 작은 앱)

동의서 화면의 **📱 문자로 서명 받기**를 누르면 이 앱의 링크가 만들어집니다.
받는 분(어르신·보호자)은 링크를 열어 **서명 칸에 손가락으로 서명**만 하면 되고, 서명은 동의서 서명란에 자동으로 들어옵니다.

- 이 앱은 개인정보를 읽지도 보여 주지도 않습니다 (이름·생년월일·전화번호 없음).
- 서명 그림만 방문기록지 폴더 안 「문자서명」 폴더에 `링크번호.png`로 저장됩니다 (7일 뒤 자동 정리, 동의서 PDF 안에는 남음).
- 링크는 3일 뒤 만료되고, 한 번 서명하면 다시 쓸 수 없습니다.
- 방문기록지 앱과 따로 두는 이유: 받는 분이 링크 주소를 고쳐도 방문기록지(어르신 명단)에 들어갈 수 없게 하려는 것입니다.

## 설치 (처음 한 번, 센터 계정 bcmedcoophome@gmail.com)

1. <https://script.google.com> → **새 프로젝트** → 이름 `문자서명`
2. `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 붙여넣기 → 저장
3. 함수 **setup** ▶ 실행 → 권한 허용
4. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (받는 분이 구글 로그인 없이 열 수 있어야 함)
5. 나온 웹 앱 주소(`…/macros/s/○○○/exec`)를 담당자에게 전달 → `home-visit/Index.html`의 `SIGN_APP_ID`에 ○○○ 부분을 넣음
